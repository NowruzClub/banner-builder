# Bidar Banner Editor

یک ویرایشگر ساده و مستقل برای GitHub Pages.
 GitHub Pages شما قابل استفاده است.

## تغییرات بعدی
برای هر بار استفاده فقط:
- تاریخ را عوض کنید.
- ساعت را عوض کنید.
- اندازه خروجی را انتخاب کنید.
- روی «دانلود PNG» بزنید.

اگر بخواهید خودِ قالب گرافیکی نیز قابل ویرایش شود، می‌توان نسخه پیشرفته‌تری ساخت که محل متن، رنگ، فونت و سایر عناصر را هم از داخل پنل کنترل کند.
